# Asset licenses

This repo has no art or audio files. Every model (kids, grown-ups, the dog, birds, equipment, trees),
every texture (grass, rubber, gravel and sand speckle, the sign) and every sound effect is generated at
runtime by the code in `js/`. All of it is original work made for this repo and covered by the code
license (Apache 2.0).

Any asset added later needs a row here before it is committed: original work, generated, or CC0.
